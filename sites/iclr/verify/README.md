## Layout

- `verify_lib.py` — deterministic utilities: frozen seed identity gate
  (table counts, full-rows sha256, file md5/sha256), answer normalization.
- `contract_engine.py` — per-task runner: trajectory identity (task id,
  exact task wording, `terminated: agent_done`, non-empty answer, same
  loopback origin+port on every step URL), decodable non-blank screenshot
  gate, navigation gates, exact DB delta (read-only row-identity / stateful
  exact adds+removes), scoped claim regexes over the normalized answer,
  dynamic answer-state bindings (registration codes), fail-closed.
- `contract.json` — per-task spec (`task`, `initial_digest`, `paths`,
  `claims`, `state`, `answer_state`). Generated by the reviewer from the
  honest-walk facts (transcribed from live pages during the real Playwright
  walkthroughs of the r2 review container `wh-iclr-r2`, 2026-09-30) and
  cross-checked against the frozen seed DB.
- `verify_0.py … verify_19.py` — one deterministic verifier per task
  (`--run_dir DIR`, exit 0 = PASS, JSON verdict on stdout).
- `append_rubrics.py` — appends `verifier_path` + `judge_rubric` to
  `tasks.jsonl` (5-key prefix bytes untouched, no answer data, English pure
  rules, idempotent).
- `test_verifiers.py` — adversarial suite: 20 honest fixtures PASS; no-op
  ×20, answer-only shortcuts, wrong answers ×20, stale-DB (stateful),
  read-only violations, and tampered packages (wrong task id / off-site
  URL / cross-port / not-terminated / empty answer / pre-mutated seed /
  broken screenshot) all FAIL.
